# Python Data Processing – Task 9

 📌 Project Overview

This project is developed as part of my **AI/ML Internship at Veda Technology**. It focuses on processing structured student records using Python and generating useful summary statistics from the data.

The project demonstrates how Python data structures, functions, loops, and built-in functions can be combined to perform basic data processing efficiently.

🎯 Objectives

- Process a collection of structured student records.
- Store and manage data using lists and dictionaries.
- Calculate useful statistical information.
- Filter student records based on marks.
- Identify the student with the highest marks.
- Organize repetitive operations using functions.

🛠️ Technologies Used

- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook
- **Concepts:** Lists, Dictionaries, Functions, Loops, List Comprehension, Lambda Functions

✨ Features

- Display student details, including name, age, marks, and department.
- Calculate the total number of students.
- Compute total and average marks.
- Identify the highest and lowest marks.
- Count passed and failed students.
- Filter students who scored 80 or above.
- Find the student topper based on marks.
